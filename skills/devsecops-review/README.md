# Skill: `devsecops-review`

Esta skill complementa a análise de vulnerabilidades trazendo a mentalidade **Shift-Left (DevSecOps)**: revisar código e configurações *antes* que cheguem à produção.

## Quando usar
Sempre que você quiser simular um **Security Gate** em um Pull Request, script de automação, Dockerfile ou endpoint novo antes do deploy.

## Exemplo de Prompt
- *"Atue como DevSecOps e revise este trecho de código antes de eu subir para produção."*
